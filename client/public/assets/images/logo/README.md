# Logo Images

This folder contains the logo images for CK Forest Garden.

## File Naming Convention

- `logo.png` - Main logo (recommended size: 200x200px or 300x300px)
- `logo-white.png` - White version of logo for dark backgrounds (optional)
- `favicon.ico` - Browser favicon (16x16px, 32x32px, 48x48px)

## Supported Formats

- PNG (recommended for transparency)
- SVG (recommended for scalability)
- JPG/JPEG (for photographs)

## Usage

The logo will be displayed in:
- Website header/navigation
- Footer
- Admin dashboard
- Email templates

## Recommendations

- Use PNG format with transparent background
- Minimum resolution: 200x200px
- Maximum file size: 500KB
- Aspect ratio: Square (1:1) or horizontal (2:1)
