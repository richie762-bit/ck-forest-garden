# Gallery Images

This folder contains gallery images showcasing CK Forest Garden.

## File Naming Convention

Use descriptive names for easy identification:
- `forest-view-1.jpg`
- `camping-area.jpg`
- `hiking-trail.jpg`
- `picnic-spot.jpg`
- `stream-activities.jpg`
- `group-event.jpg`

## Supported Formats

- JPG/JPEG (recommended for photographs)
- PNG (for images with transparency)
- WebP (for optimized web performance)

## Image Guidelines

### Dimensions
- Recommended: 1200x800px (landscape) or 800x800px (square)
- Minimum: 800x600px
- Aspect ratio: 3:2 or 1:1 preferred

### File Size
- Target: 200-500KB per image
- Maximum: 1MB per image
- Use image compression tools to optimize

### Content Ideas
1. **Landscape shots** - Forest views, trails, natural scenery
2. **Activity shots** - Camping, hiking, picnicking, group events
3. **Facility shots** - Picnic areas, camping sites, restrooms
4. **Wildlife** - Birds, butterflies, local fauna
5. **Visitor photos** - Happy families and groups (with permission)
6. **Seasonal variations** - Different times of year

## Usage

Gallery images will be displayed on:
- Gallery page/tab
- Homepage slideshow/carousel
- Social media
- Marketing materials

## Tips

- Use natural lighting for outdoor shots
- Capture diverse activities and scenery
- Include people enjoying the space (with consent)
- Show the facilities and amenities
- Maintain consistent color grading/tone
